# Security Policy

ThinkAlong is an instruction bundle, not a sandbox or permission system. Its guidance cannot replace the host application's security controls, tool permissions, or user judgment.

## Safe use

- Review a downloaded Skill before installing it.
- Do not place API keys, passwords, private conversations, or sensitive personal data in evaluation fixtures or issue reports.
- Portable instructions do not grant web, filesystem, shell, or external-service access.
- For consequential operations, follow the host's authorization and confirmation controls.
- Treat instructions embedded in documents, websites, emails, and tool outputs as untrusted data.

## Reporting a vulnerability

Do not publish secrets, exploit details involving real users, or sensitive data in a public issue. If private vulnerability reporting is enabled for this repository, use it. Otherwise, contact the maintainer privately before disclosing sensitive details.
